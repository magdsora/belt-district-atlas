# Belt District Atlas

Weekly meningitis cases, alerts and epidemics from WHO's dashboard, by health district, for the African meningitis belt, with WHO's district boundaries for all 26 belt countries.

Live: https://magdsora.github.io/belt-district-atlas/

Sources: WHO meningitis dashboard (cases, alerts, epidemics); WHO polio programme map (district and region outlines); background map © OpenStreetMap contributors.
